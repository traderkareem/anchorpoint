# AnchorPoint

An international courier and delivery platform.

## Features
- Create shipments
- Real-time package tracking
- Admin dashboard
- International support (multi-country, multi-currency)

## Tech Stack
- Node.js + Express (backend)
- MongoDB Atlas (database)
- HTML / CSS / JavaScript (frontend)
- Hosted on Pxxl
